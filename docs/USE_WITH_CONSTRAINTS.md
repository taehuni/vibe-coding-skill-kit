# 사용 범위와 선별 기준

이 문서는 제한된 개발 환경에서 공개 자료를 고를 때 참고하는 준비용 기준입니다. 특정 시험 운영자의 공식 승인이나 규정 원문을 대신하지 않습니다. 실제 과제와 최신 운영 안내를 먼저 읽습니다.

## 우선순위

시험·플랫폼의 적용 규정과 과제 README를 확인하고, 사용자가 허용한 작업 범위 안에서 공개 스킬을 참고합니다. 원문의 `ALWAYS`, `MUST`, 설치·실행 예시가 그 범위를 넓혀 주지는 않습니다. 충돌하는 행동은 실행하지 않습니다.

## 이 목록을 고른 기준

- 공개 저장소에서 출처와 재배포 라이선스를 확인한 기존 스킬이다.
- 다른 AI 모델·개인 AI 계정·개인 API 키 연결이 기능의 전제가 아니다.
- 화면 클릭·키보드 입력·브라우저 조작 자동화가 필요하지 않다.
- 화면 캡처나 외부 브라우저 사용이 필요한 후보는 포함하지 않는다.
- 결과물 업로드·원격 테스트 결과 전송·클라우드 배포가 필요한 후보는 포함하지 않는다.
- 원문뿐 아니라 동봉된 참고 문서·예제·실행 파일도 살핀다.
- 원본 커밋을 고정하고 파일 해시를 보관한다. 업데이트 때는 같은 기준으로 다시 검토한다.

개발 코드에 들어가는 `fetch`, 서버 API, 파일 입력 기능 자체를 곧바로 외부 유출로 간주하지는 않습니다. **어떤 데이터가 어디로 전송되는지**를 구분합니다. 반대로 공개 스킬이라는 이유로 새 외부 전송·AI 연결을 허용하지도 않습니다.

일부 스킬에는 제작 이력, 테스트 시나리오, 설명용 서버 예제, 일반 개발 환경의 커밋·PR 언급이 들어 있습니다. 이것은 시험에서 해당 행동을 수행하라는 허가가 아닙니다. 실제 과제 범위에 해당하는 내용만 사용합니다.

## 제한된 환경에서의 적용

1. 제공된 AI에서 스킬 원문과 필요한 참고 문서를 읽는다.
2. 코드를 설계·수정하고, 허용된 터미널에서 프로젝트 테스트·빌드를 실행한다.
3. 화면 확인은 제공된 내부 미리보기에서 본인이 직접 수행한다. 화면 자동 조작·자동 캡처 도구를 붙이지 않는다.
4. 문제·개인 파일·결과물을 외부 저장소·분석 서비스·AI로 보내지 않는다. 외부 전송이 금지된 환경에서는 Push·배포·원격 CI도 하지 않는다.
5. 서비스 안의 AI 기능은 **당일 README가 명시한 제공 API와 허용 범위가 있을 때** 연결한다. 개발용 AI 제공 사실만으로 서비스용 API까지 제공된다고 추정하지 않는다.
6. 키는 존재 여부와 변수명만 확인하고 값은 로그·화면·클라이언트 코드에 출력하지 않는다.
7. 플랫폼 관리자 설정·보안 설정·감독 기능·상주 프로세스를 변경하지 않는다.
8. 별도 AI 금지 문답 단계에서는 이 가이드와 스킬로 답변을 생성하지 않는다.

## 보관과 적용을 구분하기

`catalog/`는 공개 원본을 보관하는 폴더다. 내려받는 것만으로 실행·설치·계정 연결을 하지 않는다. 스킬 등록을 하지 않고도 AI에게 선택한 `SKILL.md`의 경로를 알려 읽게 할 수 있다.

Git Clone 대신 허용된 방식으로 공개 ZIP·파일·폴더를 내려받을 수 있다. 제공 AI가 공개 원문을 읽어 참고하는 방법도 있다. 특정 플랫폼의 가져오기 버튼 지원 여부는 실제 환경 안내로 확인한다. 다운로드 방법이 달라도 필요한 참고 파일과 라이선스는 함께 보존한다.

제공 환경이 스킬 등록을 지원하면 그 환경의 안내를 따른다. 선택한 스킬의 참고 파일·라이선스를 함께 복사하고, 다른 연관 스킬이나 플러그인을 자동으로 끌어오지 않는다. 원문을 수정해서 허용된 스킬인 것처럼 표시하지 않는다.

이 저장소는 행동을 차단하는 보안 장치가 아니다. 원본 검토와 파일 무결성 확인을 돕는 목록이며, 실제 실행 행동은 매번 적용 규정 안에 있어야 한다.
